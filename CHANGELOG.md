# Журнал изменений Region Spoof

## 1.4-alpha

Исправление запуска и усиление подбора прокси:

- **Исправлен запуск без рабочего ProxyBroker2 (баг «спуфинг вслепую»)**: раньше
  апплет включал системный прокси Windows `127.0.0.1:8888`, даже если ProxyBroker2
  не поднялся (порт не слушался), и обрывал сеть приложениям, уважающим
  системный прокси. Теперь `start()`/`set_zone()` включают прокси **только при
  успешно поднятом pb2**; при сбое `_engine_loop()` снимает мёртвый системный
  прокси (`clear_system_proxy()`) и пишет ERROR в журнал.
- **Расширены источники списков прокси** (`PB2_EXTRA_PROVIDERS`, 4 → 8 живых):
  proxyscrape v4 (фильтр US), geonode (US), TheSpeedX, monosans, proxifly,
  spys.me, встроенный proxyscrape и roosterkid. Проверено: geonode отдаёт десятки
  актуальных US-прокси.
- **Заменены мёртвые judge-сервисы** (`PB2_EXTRA_JUDGES`): встроенный набор
  proxybroker2 (httpbin.org, proxyjudge.us, зеркала azenv) целиком таймаутил —
  проверка прокси не работала. Добавлены живые judge с эхо заголовков
  (httpbingo.org/headers, httpbin.org/get?show_env, azenv.net) — проверка
  прокси возобновилась. Остаточная нестабильность HTTP-судьи отмечена (влияет
  только на доступность типа SOCKS5; HTTPS-прокси подбираются стабильно).
- **Исправлена сборка `pb2.exe`**: в дистрибутив добавлена база стран
  `GeoLite2-Country.mmdb` (без неё `pb2.exe` падал с `FileNotFoundError`, порт
  не открывался) — первопричина «спуфинга вслепую».
- **Версия**: `applet.py` → `APP_VERSION = "1.4-alpha"`, `build/installer.iss`
  → `1.4-alpha` (`VersionInfoVersion=1.4.0`); `RegionSpoof.exe` пересобран.
  Тег релиза бинарников в `download_binaries.py` не меняется (остаётся
  `v1.3-alpha` — там лежат sing-box/mihomo/wintun).

## 1.3-alpha

Приведение репозитория в соответствие с лицензией GPL-3.0 и вынос
сторонних бинарников в GitHub Releases:

- **Лицензия**: добавлен полный текст GNU GPL v3.0 — файл `LICENSE`
  (получен с gnu.org, без сокращений). Кредиты сторонним авторам,
  условия некоммерческого использования и отказ от ответственности
  сохранены в файле `NOTICE` (бывший `LICENSE.txt`, переименован —
  информация не потерялась).
- **Бинарники вынесены из git**: `bin/singbox/sing-box.exe` (~78 МБ),
  `libcronet.dll` (~9 МБ), `LICENSE` и `bin/mihomo/mihomo-windows-amd64-v1.exe`
  (~58 МБ) удалены из индекса (`git rm --cached`; файлы с диска сохранены),
  добавлено правило `bin/` в `.gitignore`. История git НЕ переписывалась.
- **Релиз `v1.3-alpha`**: вложения `region-spoof-bin-singbox-1.14.0.zip`,
  `region-spoof-bin-mihomo-v1.zip` и `region-spoof-bin-wintun.zip` с файлом
  `SHA256SUMS` (контрольные суммы всех вложений).
- **Скрипт `download_binaries.py`**: загрузка бинарников из Releases с
  ОБЯЗАТЕЛЬНОЙ проверкой SHA256 (несовпадение = отказ от распаковки,
  файл удаляется, понятная ошибка с ожидаемым и фактическим хэшом) и
  распаковка в `bin/` в структуре, которую ищет `applet.py`
  (`find_binary`, `find_wintun`); только стандартная библиотека Python —
  работает до установки зависимостей; защита от Zip Slip.
- **`install.bat`**: после установки Python-зависимостей автоматически
  вызывает `download_binaries.py`; при сбое загрузки выводится
  предупреждение, но установка не прерывается (системный прокси
  работает и без бинарников).
- **README**: раздел «Установка» дополнен описанием загрузки бинарников;
  раздел «Лицензия» переписан под GPL-3.0 (ссылки на исходники sing-box,
  mihomo и wintun, благодарности, требования к системе, отказ от
  ответственности, некоммерческий характер использования).
- **`build/installer.iss`**: версия 1.3-alpha (`VersionInfoVersion=1.3.0`),
  установка файлов `LICENSE` и `NOTICE` вместо `LICENSE.txt`.
- **`applet.py`**: обновлён `APP_VERSION = "1.3-alpha"` (только версия).
- **Установщик 1.3-alpha (решено)**: пересборка `RegionSpoof-1.3-alpha-Setup.exe`
  выполнена — Inno Setup 6.7.3 установлен в окружение сборки; `applet.py` и
  `pb2_runner.py` собраны через PyInstaller 6.22.3 в `dist\RegionSpoof\`
  (`RegionSpoof.exe`, `pb2.exe`, `bin\`), установщик собран ISCC из
  `build\installer.iss` и загружен в релиз `v1.3-alpha` (79,6 МБ).
- **Wintun (решено)**: TUN-драйвер `wintun.dll` добавлен в релиз отдельным
  вложением `region-spoof-bin-wintun.zip` — официальная сборка 0.14.1 с
  wintun.net, подпись WireGuard LLC (DigiCert EV) проверена как `Valid`;
  распаковка в `bin\wintun\bin\amd64\wintun.dll`, как ищет `find_wintun`.
  TUN-связки теперь работают «из коробки» после `install.bat`.
  Обращено внимание: лицензия готовых `wintun.dll` — «Prebuilt Binaries
  License» WireGuard LLC (не MIT и не Microsoft); исходный код проекта
  Wintun — GPLv2. Распространение вместе с программой разрешено п. 3(d)
  этой лицензии; в `NOTICE` и `README` уточнена принадлежность и лицензия.

## 1.2-alpha

Реализованы требования Р7.1–Р7.5 реестра требований к ИИ
(автоматизация, авто-фолбэк, полное логирование, автоскан портов,
перезапуск с индикацией):

- **Р7.1** — настройки «из коробки»: функциональные дефолты в коде,
  `config.json` остаётся переопределением; во вкладке «Сеть» GUI добавлены
  поля основного порта, запасных портов, списка сканирования и таймаута
  проверки (сохраняются в `config.json`).
- **Р7.2** — авто-фолбэк с проверкой результата: после запуска ProxyBroker2
  выполняется проверка подъёма (TCP-коннект, таймаут из конфигурации);
  при неудаче — перезапуск на запасном порту с повторной проверкой; ошибка
  показывается пользователю в GUI без падения приложения.
- **Р7.3** — полное логирование: `logs\applet.log` с ISO-временем и ротацией
  (`applet.log` → `applet.1.log`, лимит 2 МБ); действия пользователя
  логируются с маркером `[action]`.
- **Р7.4** — автоскан портов при запуске (в фоне): выбор первых двух свободных
  портов (основной + запасной) из `scan_ports`; при переключении на запасной —
  повторное сканирование нового запасного.
- **Р7.5** — перезапуск при смене порта с предупреждением и индикацией времени:
  в GUI выводится уведомление «Порт изменился: X → Y» со счётчиком секунд и
  итоговым «перезапуск занял N с».

Прочее:

- версия обновлена до `1.2-alpha` (`applet.py` — `APP_VERSION`, `build/installer.iss`);
- новые поля конфигурации: `spare_ports`, `scan_ports`, `pb2_start_timeout_sec`;
- иконка трея и консоль ожидают завершения автоскана перед автостартом.
