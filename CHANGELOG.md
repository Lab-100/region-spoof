# Журнал изменений Region Spoof

## 1.2-alpha

Реализованы требования Р7.1–Р7.5 реестра требований к ИИ
(автоматизация, авто-фолбэк, полное логирование, автоскан портов,
перезапуск с индикацией):

- **Р7.1** — настройки «из коробки»: функциональные дефолты в коде,
  `config.json` остаётся переопределением; во вкладке «Сеть» GUI добавлены
  поля основного порта, запасных портов, списка сканирования и таймаута
  проверки (сохраняются в `config.json`).
- **Р7.2** — авто-фолбэк с проверкой результата: после запуска ProxyBroker2
  выполняется проверка подъёма (TCP-коннект, таймаут из конфигурации);
  при неудаче — перезапуск на запасном порту с повторной проверкой; ошибка
  показывается пользователю в GUI без падения приложения.
- **Р7.3** — полное логирование: `logs\applet.log` с ISO-временем и ротацией
  (`applet.log` → `applet.1.log`, лимит 2 МБ); действия пользователя
  логируются с маркером `[action]`.
- **Р7.4** — автоскан портов при запуске (в фоне): выбор первых двух свободных
  портов (основной + запасной) из `scan_ports`; при переключении на запасной —
  повторное сканирование нового запасного.
- **Р7.5** — перезапуск при смене порта с предупреждением и индикацией времени:
  в GUI выводится уведомление «Порт изменился: X → Y» со счётчиком секунд и
  итоговым «перезапуск занял N с».

Прочее:

- версия обновлена до `1.2-alpha` (`applet.py` — `APP_VERSION`, `build/installer.iss`);
- новые поля конфигурации: `spare_ports`, `scan_ports`, `pb2_start_timeout_sec`;
- иконка трея и консоль ожидают завершения автоскана перед автостартом.
