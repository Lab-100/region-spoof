# Region Spoof Applet

Апплет системного регион-спуфинга для Windows: подбирает **общедоступные прокси
выбранной страны** (через ProxyBroker2) и направляет трафик всех приложений
через них так, чтобы сервисы за рубежом видели исходящий адрес нужного региона.

## Возможности

- **Подбор прокси автоматически**: ProxyBroker2 находит и проверяет публичные
  прокси выбранной страны, держит локальный прокси `127.0.0.1:8888` с авторотацией.
- **Три способа маршрутизации** (переключение в конфигурации / окне / трее):
  - `system` — системный прокси Windows (Windows Proxy Settings) — работает без прав администратора;
  - `singbox` — TUN-туннель через sing-box (обязателен запуск от администратора);
  - `mihomo` — TUN-туннель через mihomo (обязателен запуск от администратора).
- **Рубильник зоны**: «Зарубежный регион» ↔ «РФ (локально)» — одним кликом.
- **Список регионов** для большинства ИИ-сервисов (США, Германия, Нидерланды, …).
- **Индикация**: цветная «лампочка» в окне и иконка в трее
  (серый — выкл., жёлтый — подключение, зелёный — регион подтверждён, красный — ошибка);
  в подсказке трея и окне показывается фактический регион и IP.
- **Кнопка «Проверить регион»** — принудительная проверка исходящего региона.
- **Автопереключение**: если активная связка не запустилась/упала, апплет
  переходит на следующую связку; последняя рабочая связка запоминается и
  включается при следующем запуске (если включён автостарт).
- **Журнал**: окно-журнал приложения и файлы логов `logs\`.

## Установка

1. Установите Python 3.10–3.12 с [python.org](https://www.python.org/downloads/).
   При установке отметьте **«Add python.exe to PATH»**.
2. Запустите `install.bat` (ставит `proxybroker2`, `pystray`, `Pillow`, `requests`).
3. Убедитесь, что в папке `bin\` лежат бинарники (при необходимости скачайте сами):
   - `bin\singbox\...\sing-box.exe` — https://github.com/SagerNet/sing-box/releases
   - `bin\mihomo\...\mihomo.exe` — https://github.com/MetaCubeX/mihomo/releases
   - `bin\wintun\bin\amd64\wintun.dll` — https://www.wintun.net/
     (нужен только для TUN-связок `singbox`/`mihomo`; системный прокси обходится без него)
4. Запустите `run.bat`.

## Использование

- Кнопка **Старт** — поднять связку (подбор прокси + маршрутизация).
- Кнопка **Стоп** — всё выключить и вернуть настройки Windows.
- **Зарубежная зона (спуфинг)** — галочка-рубильник: снята = РФ (прямой трафик),
  установлена = выбранный регион.
- **Регион** — выбор страны для исходящего трафика.
- **Связка** — выбор способа маршрутизации.
- **Проверить регион** — показать фактический регион исходящего соединения.
- Сворачивание окна прячет его в трей; управление доступно и из меню трея.

Подключение считается успешным, когда найден хотя бы один рабочий публичный
прокси выбранной страны и проверка подтвердила её — тогда лампочка зелёная,
в трее и окне видно название региона и IP.

## Конфигурация

Файл `config.json` рядом со скриптом:

- `region` — выбранный регион (ISO-код) для зарубежной зоны;
- `regions` — список доступных регионов (код + русское название);
- `strategy` / `last_working` — активная / последняя рабочая связка;
- `zone` — `foreign` (зарубежье) или `ru` (РФ);
- `proxy_port` — локальный порт подбора прокси (по умолчанию 8888);
- `check_interval_sec` — период авто-проверки региона;
- `verify_timeout_sec` — таймаут одной проверки;
- `failover_threshold` — число неудачных проверок до «красной» лампочки;
- `auto_start` — включать последнюю рабочую связку при запуске приложения.

## Ограничения

- Публичные прокси ненадёжны и **небезопасны** (видят ваш трафик).
  Для конфиденциальной работы с API-ключами рекомендован собственный VPS/платный прокси.
- TUN-связки (`singbox`, `mihomo`) требуют запуска от администратора и `wintun.dll`.
- Системный прокси (`system`) распространяется на приложения, уважающие
  настройки прокси Windows; не на всё (например, не на часть игр).
- Проверка региона использует внешние сервисы ipapi.co / ipinfo.io / ip-api.com.
